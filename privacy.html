1. Application and operator

Yujin Life Gmail is a personal-use Gmail integration maintained by JeremyZhangSYD. It operates inside an owner-controlled, private Yujin workspace, not on this public website. This policy describes the Gmail integration and these informational pages; it does not describe every other private-workspace integration.

This website does not offer account registration, Google sign-in, a public AI service, or access to the owner's workspace.

2. Data accessed and permissions

The integration requests only the Google OAuth scope https://www.googleapis.com/auth/gmail.readonly, after the owner authorizes the expected Google account.

  • Account email address, to verify and bind the authorized mailbox.
  • Message and thread IDs, sender, subject, dates, snippets, and bounded search results.
  • Selected message plain-text bodies when needed for the owner's request.
  • OAuth access and refresh tokens needed to authenticate and maintain the connection.

The integration does not send, delete, archive, label, mark messages as read, or create Gmail drafts. It does not download attachments or render message HTML. It may propose a reply stored as a private local draft; that is not a Gmail draft and is not sent.

3. Purpose, AI processing, and sharing

Gmail data is used to answer the owner's mailbox questions, summarize relevant messages, identify possible follow-ups, and prepare optional local reply suggestions. Search ranges and message reads are bounded by the owner's request and the integration's limits.

AI processing is not necessarily on-device.

Relevant message metadata, snippets, selected text and conversation context may be sent to the AI inference service configured by the owner for the Life agent. This transfer supports the requested, user-facing summary or suggestion. Gmail OAuth credentials are not included in model prompts.

The owner chooses the processing service and should review its data-handling and retention terms before use. This notice does not promise zero retention by an independent provider. The Gmail integration does not automatically forward personal mail to a separate Claude workflow or publish it to this documentation site.

The application does not sell Gmail data, use it to serve advertisements, supply it to data brokers, or use it to train a generalized AI model. Use and transfer of information received from Google APIs are subject to the Google API Services User Data Policy, including its Limited Use requirements. Transfers are limited to the owner-authorized application features described here.

4. Storage, security, and retention

OAuth credentials are kept in private files in the owner's runtime, outside this public repository. The private backend binds access to the configured owner and Life channel and checks the exact read-only scope. Google API calls use HTTPS.

Questions, generated responses, source IDs, execution records and selected email excerpts may remain in the private application's conversation database, agent session records and owner-managed backups. They are not stored in these static web pages or deliberately uploaded to this public repository.

There is no fixed automatic deletion period currently promised by the private application. The owner is responsible for managing local records, sessions and backups. Revoking Google access does not itself delete previously generated summaries or independent provider logs. No claim of end-to-end encryption, Google verification, or independent security certification is made.

5. Your control, disconnection, and removal

The owner can stop new Gmail access by removing the application's authorization from Google Account third-party connections. Access can also expire or be revoked by Google. Renewing access requires the owner's Google consent when the refresh grant is no longer valid.

The owner can separately manage or remove private conversation records, local credentials and backups using their own trusted administrative process. This documentation site has no mailbox-deletion tool and cannot erase records held by another provider. For assistance with data handling, contact the maintainer without posting private material publicly.

Any future expansion of the requested Google permissions or a new use of Gmail data must be disclosed and authorized before it is enabled.

6. This public website

These pages are static documentation hosted on GitHub Pages. They contain no mailbox data, credentials, analytics scripts, advertising, forms, application cookies, or browser storage written by this site.

The hosting provider may receive ordinary web request information, such as an IP address and browser information, when serving the site. Its handling of that information is described in the GitHub General Privacy Statement. Following an external link takes you to that provider's website and policies.

7. Contact and policy changes

For general application or privacy questions, use the project issue tracker. It is public: do not include email contents, tokens, passwords, account identifiers, or other sensitive information. Private data questions should be handled directly with the owner through a trusted private channel.

Changes will be published here with an updated effective date. Material changes to Gmail data access, use or sharing must also be disclosed in the private application before new use or additional consent is requested.
